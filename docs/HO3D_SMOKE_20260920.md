## 复现命令（完整路径）

以下命令在远程服务器执行。训练输出目录为 smoke 专用；重复执行会写入同一日志目录，首次结果见报告。

```bash
cd /root/code/vepfs/repos/HUG-for-Recon-Gen
/root/code/vepfs/miniconda3/envs/hug_mediapipe/bin/python -m torch.distributed.run --standalone --nproc_per_node=4 -m src.train --config /root/code/vepfs/repos/HUG-for-Recon-Gen/configs/train_ho3d_smoke.yaml
```

使用保存的 checkpoint 独立评测：

```bash
cd /root/code/vepfs/repos/HUG-for-Recon-Gen
/root/code/vepfs/miniconda3/envs/hug_mediapipe/bin/python -m torch.distributed.run --standalone --nproc_per_node=4 -m src.eval_test --config /root/code/vepfs/repos/HUG-for-Recon-Gen/configs/train_ho3d_smoke.yaml --ckpt /root/code/vepfs/HUG-for-Recon-Gen/ho3d_smoke_20260920/training/model.pt --weights ema
```

正式全量训练配置已备好，此次只运行 smoke。正式训练需另行启动，batch/GPU=32 是保守初始值，未验证其峰值显存或吞吐。


## 实际结果

四卡训练命令退出码 0；step 3、6 验证/保存成功，全部 rank 正常结束。6 步 loss 与 grad norm 有限；rank 0 记录 loss 从 4.645715 到 3.931973，不同 batch 不用于判断收敛。checkpoint 所有浮点模型状态有限。EMA 累计更新 4 次。

检查 Adam 二阶矩，16 个 LoRA 参数张量及 shape 输出头均有非零梯度，optimizer step=6；LoRA B 参数已从零初始化更新。64 样本训练池、全局 batch=8，此次训练消费 48 次样本实例，不声称训练遍历了全部 64 帧；CPU loader 检查读取了全部 64 帧。

独立四卡 `src.eval_test` 从 model.pt 加载 EMA 成功，官方 evaluation 子集 16 帧全部完成，使用 rtmpose_cache 条件，所有指标有限。子集 PA-MPJPE=12.9520 mm、PA-MPVPE=12.4743 mm；这只是 6 步的功能性结果，不能作为正式性能结论。评测结果包含每个数据集实际使用的条件源和缓存路径。

16 项回归测试通过：native MANO、geometry overlay、augmentation/cache、预训练归一化保护。训练日志存在现有库的弃用提示和 bf16 RMSNorm 未走 fused 实现提示，不影响本次正确性，未修改这些性能相关行为。
