# 数据增强无效 & MPJPE/PA-MPJPE 差距分析

日期：2026-09-07
实验对象：`20260906_v13_dexycb_only_canonical`(开增强)vs `20260905_v11_canonical` / `20260906_v12_dexycb_only_canonical`(未开增强)

---

## 一、数据增强为什么没带来收益

### 结论

**数据增强确实生效了(没有静默失效),但在 canonical 数据 + PA 指标的设定下,它本质上提供不了预期的 ~1mm 收益。**

### 证据

1. **增强确实在跑。** v12(dexycb-only、未开增强,与 v13 唯一差别是增强开关)是干净对照:v13 的训练 loss 在每个相同 step 都稳定高于 v12(如 step 9020:0.309 vs 0.274),说明增强噪声真实进入了训练。

2. **增强效果中性甚至略负。** v12 vs v13 相同 step 的 dexycb_s0_val(model 权重):

   | step | v12 无增强 pa_mpjpe | v13 有增强 pa_mpjpe |
   |---|---|---|
   | 5000 | 7.106 | 7.256 |
   | 10000 | **6.750** | **6.840** |

   全程持平或略差,不是"还没体现出来"。

### 原因(按权重排序)

1. **PA 指标对仿射增强天然免疫。** pa_mpjpe/pa_mpvpe 是 Procrustes 对齐后的指标,旋转/缩放/平移已被对齐消除;而 affine 增强(scale ±30%、rotation ±30°、translation)教给模型的恰恰是对这类变换的不变性——**增强提供的核心能力,指标设计上就测不出来**。

2. **Canonical 数据下训练/测试同分布,没有泛化缺口可填。** `dexycb_v2_canonical_right` 已统一右手并规范化;val 与 train 同域。仿射增强只是把同一样本重新参数化(K 同步左乘 homography、2D 标签用增强后 K 重投影,train.py:894 附近逻辑正确),对模型是等价的学习问题,反而增加了不变性负担,所以略差。

3. **增强强度太弱。** depth_noise_std=1.5mm、dropout 3%、温和 color jitter,正则化量级远小于 run 间噪声(~0.05–0.1mm),不可能产生 1mm 级变化。

4. **DINOv2 冻结的部分影响。**
   - 颜色增强 ≈ 白做:DINOv2 预训练自带大量光度增强,冻结特征对 color jitter 已近似不变;
   - 仿射增强:冻结特征无法适配旋转/缩放新分布,不变性学习负担全在下游 fusion/DiT;
   - 深度增强走可训练的 PointNeXt 分支,理论上最能受益,但强度太弱。

5. **原对照不干净。** v11 训练集含 ho3d,v13 是 dexycb-only,差异不只是增强开关;且 v13 没评 ho3d_eval——如果 1mm 预期来自跨域泛化(HO3D 等 out-of-domain 场景,文献中增强收益主要来自这里),该实验没有测量窗口。

### 建议

- 想验证增强价值:在**跨域评测**(恢复 ho3d_eval)或**小数据/过拟合场景**(砍一半训练样本)下做 v12 vs v13 式干净对照。
- 若目标就是 dexycb 上的 PA-MPJPE:当前增强方向不对,可考虑加强深度噪声/dropout(模拟真实 sensor),而不是仿射。
- v13 已现轻微过拟合迹象(23k→25k:pa_mpjpe 6.469→6.456 但 mpjpe 23.38→23.74),增强的正则化收益可能需更长训练才显现,但量级大概率仍是 0.1mm 级。

## 二、MPJPE 与 PA-MPJPE 差距高达 ~20mm 的原因

### 实测误差分解

用 v13 EMA 权重在 519 个 dexycb_s0_val 样本上逐级对齐分解(脚本:`scratch/diag_mpjpe_gap.py`):

| 阶段 | 误差 | 说明 |
|---|---|---|
| raw MPJPE | **24.79 mm** | |
| 腕点平移误差 | **21.03 mm** | ← 最大单一来源 |
| 去掉平移后 | 17.76 mm | 旋转+缩放+关节 |
| 刚体对齐后 | 6.70 mm | 全局旋转贡献约 11mm |
| PA(相似变换) | 6.45 mm | scale≈0.991,几乎无贡献 |

**约 2/3 的差距来自绝对平移,1/3 来自全局旋转,手型/关节本身只有 6.45mm。**

逐轴分解(腕点,mean abs):x 9.6 / y 8.2 / **z 13.0 mm**,z 的 std 高达 26mm(重尾,少量样本深度估计严重偏离)。各轴均值偏差很小(x 0.18 / y 1.57 / z 3.89mm),**排除坐标系/腕点约定 bug**,是真实的估计误差。

### 为什么"正常应差 2mm 以内"不适用

2mm 差距只在 **root-relative 评测**(或平移由 GT/外部模块给出)时成立。本模型端到端预测相机系下的 t(3)+R(6),GT 腕点在 0.48–1.44m 远处,平移误差全额计入 MPJPE。参照:HaMeR 在 DexYCB 上绝对 MPJPE ~10mm(gap ~5mm),也是类似量级,只是本管线全局位姿更弱。

### 结构性原因

1. **t/R 只是 109 维 flow 目标中的 9 维**,lambda_v=1 的归一化 MSE 对全局位姿没有特殊加权;几何损失里只有 joint_abs(50% 权重)隐式监督平移。
2. **几何损失乘了 (1−t) 时间权重**:高噪声 timestep(全局结构恰恰在此阶段形成)几乎得不到几何监督,监督信号与误差形成阶段错位。
3. PCL crop 半径仅 20cm 且以 query 点为中心,不是度量定位的强锚点;z 方向(深度)是图像估计最难的轴,误差重尾。

### 解决方案(按优先级)

1. **显式监督全局位姿**:给 t 和 R_6d 加独立损失项(L1 on t,单位米;6D 旋转 L1/余弦损失),权重与关节损失解耦。最直接。
2. **修复时间权重错位**:几何损失(至少 t/R 部分)不要整体乘 (1−t),或对全局维度用 min-SNR 类加权,保证高噪声步也监督全局结构。
3. **平移相对化(治本)**:PCL 本身是度量的——改为预测"腕点相对 PCL crop 中心/手部质心的偏移",把绝对定位变成相对回归,z 误差会显著下降;或加预测 PCL 质心的辅助任务。
4. **评测口径**:对比时区分 root-relative 与 absolute MPJPE;与 HaMeR 类方法比绝对值时确认对方是否用了 GT root 或独立 root 估计。
5. **可选**:解冻 DINOv2 最后 2–4 层(或加 LoRA adapter),让图像分支为度量位姿任务专门化;采样步数 50→100 可小幅降生成方差。

**若只做一件事:先做 1+2(改损失),成本最低、直接命中 21mm 的平移误差来源;3 更治本但要动模型输入接口。**
